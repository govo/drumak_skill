## Drum AI とは

**Drum AI は、iPhone、iPad、Mac 向けの AI ドラムマシン兼練習アプリです。** 楽曲を取り込むとドラムを分離し、テンポを検出して、編集可能なパターンに変換します。そこからは本格的なドラムマシンとして使えます。24 種類のプロ向けキット、16/32 ステップのシーケンサー、コンプレッサーとフェイザーを備えたミキサー、ヒューマナイズ、そして難しいフレーズを目標のテンポまで引き上げるためのテンポドリルです。

- **AI ドラム認識。** オンデバイスのステム分離により、取り込んだ楽曲や録音からキック、スネア、ハイハット、シンバルを抽出します。
- **24 種類のプロ向けキットと 16/32 ステップのシーケンサー。** ボイスごとのレベル、パン、フィルター、チューン、ディケイに加え、4/4、3/4、6/8、三連符、ブルースシャッフルに対応します。
- **ワンタップでパターン生成。** 認識した楽曲は、ドラッグしたり、小節ごとにコピーしたり、グルーヴを付け直したりできる編集可能なパターンになります。
- **Tempo Drill。** AB ループ、複数の速度セグメント、カウントイン、スキップして次へ。速すぎて弾けない部分を練習するために作られています。
- **無料でダウンロード。** 無料プランでもドラムマシンと練習機能は使えます。AI 認識機能には週あたりの上限があります。任意の Drum AI Pro サブスクリプションで、その上限がなくなります。
- **1 つのアプリ、3 つのデバイス。** iPhone、iPad、Mac で同じプロジェクトファイルを共有します。

## このスキルができること

このリポジトリにはアプリ本体は含まれていません。これは **AI アシスタント向けのスキル**(Claude Code、および MCP に対応するあらゆるクライアント)です。インストールすると、アシスタントは Drum AI の PRESET サービス——アプリが使っているのと同じシーケンスエンジン——に直接アクセスできるようになります。

具体的には、次のとおりです。

- やりたいことを言葉にするだけです。「140 BPM のロリングハイハット入りトラップビートを作って」「90 BPM のブーンバップのグルーヴが欲しい」「ダブルベースのメタルパターンを書いて」など。
- アシスタントがキットを選び、パターンをボイスごとに書き、細部を詰めます。ベロシティのアクセント、ラチェット、フラム、グルーヴ、ヒューマナイズまで。
- 返ってくるのは **リンク 1 本** だけ。リンクを開いてプレビューを確認し、パターンを Drum AI に取り込みます。

逆方向も可能です。アプリにすでにあるパターンを貼り付ければ、アシスタントがそれを読み取り、ドラムが何をしているのかを説明し、作り直します。

**できないこと:** アシスタントがアプリをインストールしたり、開いたり、パターンを取り込んだりすることはできません。取り込みは、リンクからご自身のデバイスでワンタップです。

### このスキルをインストールする

Claude Code では、2 つのコマンドです。

```
/plugin marketplace add govo/drumak_skill
/plugin install drumai-preset@drumai
```

インストールはこれだけです。プラグインが自身の MCP サーバー宣言を持っているため、サービスは自動的に登録されます。入力するアドレスも、編集する設定ファイルもありません。

あとは欲しいビートを説明するだけです。サーバーが接続されているかどうかは `/mcp` で確認できます。

**その他の MCP クライアント**(Claude Desktop、Cursor など):クライアント自身の設定に次のブロックを追加してください。

```json
{
  "mcpServers": {
    "drumai-preset": {
      "type": "http",
      "url": "https://c1c1.online/drumai_mcp/mcp"
    }
  }
}
```

**MCP クライアントをまったく使わない場合** 同じサービスに到達するシェルスクリプトと、素の JSON-RPC の経路も用意しています。必要要件、設定、スクリプトのインターフェース、トラブルシューティングは [references/setup.md](references/setup.md) にまとめています。

## よくある質問

### Drum AI とは何ですか?

Drum AI は、ドラムマシン、AI ドラム認識、練習ツールを組み合わせた iPhone、iPad、Mac 用アプリです。楽曲を取り込んでドラムを編集可能なパターンとして採譜させたり、ステップシーケンサーと 24 種類のキットで自分でビートを書いたりできます。ダウンロードは無料で、AI 処理はすべてお使いのデバイス上で行われます。

### Drum AI はドラムマシンですか、それとも採譜アプリですか?

どちらでもあり、そこが要点です。採譜側は音声を聴いてパターンを生成し、ドラムマシン側はそのパターンが存在し、編集され、演奏される場所です。アプリが採譜したパターンも、手で書いたパターンも、同じエディタ上の同じ種類のオブジェクトなので、自由に混ぜ合わせられます。

### Drum AI は無料ですか?

Drum AI は無料でダウンロードでき、作成が必要なアカウントもありません。無料プランでもドラムマシンと練習機能はすべて利用できますが、AI 認識機能には週あたりの上限があります。ステム分離 3 回、パターン生成 3 回(いずれも 1 週間あたり)、保存できる認識履歴 1 件、ご自身の PRESET 3 件です。Drum AI Pro は、これらの上限をすべてなくす任意のサブスクリプションです。

### Drum AI はどのプラットフォームで動作しますか?

Drum AI は iPhone、iPad、Mac で動作する 1 つのユニバーサルアプリで、同じプロジェクトファイルを 3 つすべてで開けます。iPhone でビートの下書きを作り、Mac で練り上げる、といったことが、手作業での書き出しや同期なしにできます。

### Drum AI はオフラインで動作しますか? 音声はどこかにアップロードされますか?

認識モデルである LarsNet はお使いのデバイス上で動作するため、解析のために音声がサーバーへ送られることはありません。ファイルを取り込むかマイクで録音すると、分離はローカルで行われます。認識に関してネットワーク接続が必要な要素はありません。

### Drum AI Preset スキルとは何ですか?

Drum AI Preset スキルとは、このリポジトリのことです。AI アシスタントを Drum AI の PRESET サービスに接続するアドオンで、ビートを言葉で説明すると、アプリに取り込めるパターンが返ってきます。アプリを置き換えるものではなく、アプリに供給するものです。

### このスキルを使うのに自分のサーバーは必要ですか?

いいえ。スキルは既定で Drum AI の PRESET サービスの公開デプロイを参照するため、インストール後そのまま動作します。自分でコピーを動かすことが役立つのは、サービスに対して開発を行う場合だけです。

### どの AI アシスタントがこのスキルを使えますか?

Claude Code、Claude Desktop、Cursor など、MCP をサポートするあらゆるクライアントです。Claude Code が最も簡単な経路で、このリポジトリをプラグインとしてインストールするとサービスが自動的に登録されます。MCP は使えないもののシェルを実行できるクライアントは、同梱のスクリプトを利用できます。ChatGPT のようにテキストしか読めないアシスタントでも、サービスのアドレスを指定すればパターン作成は同じように機能します。

### どんな音楽ジャンルを書けますか?

ドラムマシンが表現できるあらゆるジャンルです。トラップ、ハウス、テクノ、ヒップホップとブーンバップ、ファンク、ブレイクビーツ、シャッフル、ロック、そしてダブルベースのメタル。サービスには出発点として 8 つのスタイル骨格、行を変化させる 20 のフィルモード、完成したビートがアプリ内でどう見えるかを示す 22 のリファレンスパターンが用意されています。アシスタントはそれらをそのまま適用するのではなく、あなたの説明に合わせて調整します。

### ドラムキットはいくつありますか?

24 キットで、アプリに同梱されているものと同じです。808 やトラップキットからハウス、テクノ、アコースティック、パーカッションセットまで、エレクトロニックとアコースティックの領域をカバーしています。アシスタントが希望のスタイルに合わせてキットを選び、あとからアプリ内でパターンを書き直すことなくキットを差し替えられます。

### 実際の楽曲のドラムを採譜できますか?

スキル単体ではできません。採譜はアプリの役割です。お使いのデバイスで楽曲を Drum AI に取り込むと、キック、スネア、ハイハット、シンバルを分離し、編集可能なパターンに変換します。スキルはそのループのもう半分で、パターンができたあとに、アシスタントがそれを読み、ドラムが何をしているのかを説明し、練習用チャートや新しいバリエーションに書き換えられます。

### アシスタントがパターンをアプリに取り込んでくれますか?

いいえ。アシスタントの出力はリンクです。お使いのデバイスでリンクを開き、プレビューを確認して、そのページから取り込みます。取り込みをタップするまで、アプリには何も届きません。

### 取り込みリンクには何が含まれますか?

1 本のリンクにパターン全体が入っています。キット、テンポ、拍子、そしてすべてのヒットとそのベロシティ、ラチェット、フラムです。開くとプレビューページが表示され、そこから取り込むとパターンが Drum AI に入ります。ダウンロードするファイルも、アカウントもありません。

### 生成されたパターンはアプリ内で編集できますか?

はい。アプリに届くのはごく普通のパターンで、手で打ち込んだものと同じです。すべてのヒットは移動、削除、ベロシティの変更ができ、キットの差し替えも、グルーヴとヒューマナイズの設定変更も、アプリの通常のツールで行えます。

### Drum AI Pro には何が含まれますか?

Drum AI Pro は、無料プランの上限を取り除く任意のサブスクリプションです。ステム分離が無制限、ビート認識とパターン生成が無制限、認識履歴が無制限、ご自身の PRESET が無制限、テンポドリルの登録・セグメント・起動が無制限になります。ドラムマシンと練習機能はどちらのプランでも同じように使えます。

### Drum AI の PRESET とは何ですか?

PRESET は保存されたドラムパターンです。キット、トランスポート設定、ヒットのグリッドからなります。PRESET は共有したり取り込んだりする対象で、このスキルが生成するプレビューリンクは、移動中の PRESET です。アシスタントからアプリへパターンを運びます。
